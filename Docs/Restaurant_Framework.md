# 农场 + 餐厅经营框架（讨论稿）

> 2026-10-27 讨论结论。种地玩法暂缓；本文件只定经营侧框架，供后续实现对照。  
> 现有工程：`FarmSim25D` / `Lvl_TopDown`，时间与灯光由 `FarmClock` 驱动。

## 1. 产品一句话

上午像星露谷物语在农场生活；下午五点回自家餐厅，用「速速上菜」式跑堂把客人伺候完；晚上十一点打烊。种田与餐厅先分开做，再用同一套物品/金钱拼起来。

## 2. 已敲定

| 项 | 结论 |
|---|---|
| 一天节奏 | 06:00 开日 → 17:00 进入营业段 → 23:00 打烊 → 之后自由 → （沿用）约 02:00 强制休息/日结 |
| 上午段内容 | 种田、探索、商店买种子、NPC 剧情（类星露谷）；种地实现可后接 |
| 营业段内容 | 顾客点菜 → 厨房做菜 → 上菜 → 收钱；参考「速速上菜」 |
| 餐厅场景 | **不切关卡**：在当前 `Lvl_TopDown` 内划区 |
| 餐厅选址 | **南桥 / 码头一侧** |
| 操作手感 | **偏动作**：玩家在餐桌 ↔ 厨房之间跑；灶台 / 出餐口交互 |
| 持有物 | **一次只端 1 盘** |
| 互动键 | **统一按 E**（靠近桌 / 灶台 / 出餐口；种地暂停期间 E 先给餐厅） |
| 世界交互 | **情境 E**：对床=睡觉，对商店物体=开商店 UI，对桌/灶台=餐厅；快捷键互不兼任 |
| 客人超时 | **耐心耗尽直接离席，不给钱** |
| 美术 | **继续用 VMF 体素资产**摆桌椅灶台 |
| 开业规则 | **17:00 后玩家自选何时开业**；晚开只缩短营业时段、影响当日营收，无额外扣分 |
| 与种地关系 | 第一版餐厅食材用调试库存 / 商店基础食材；以后田里产出进同一库存再被菜谱消耗 |

## 3. 日模式（挂在 FarmClock）

```
FarmMode        06:00–17:00   农场自由
RestaurantMode  17:00–23:00   客流 + 厨房/桌交互生效
FreeMode        23:00–02:00   打烊后自由；02:00 日结睡觉
```

### 日末关店（02:00 / RequestEndDay）

- 任意路径进入 `FarmClock.RequestEndDay`（床 E → `TrySleep`，或时钟 `Minutes >= 1560` ≈02:00）都会先调用餐厅 `ForceCloseForSleep`：停开业、清客人/持菜、关招牌、重置日计数；已打烊时仍幂等重置 hint。
- 床路径会先 ForceClose 再 TrySleep，日末再次 ForceClose 无害。
- 勿再依赖玩家按 B 睡觉；睡觉入口是农舍旁 **Farm_Bed** 的 **E**。

- 17:00 起可开业；玩家到餐厅再开始营业。晚开 = 可营业时间变短 = 营收上限变低，不另扣评价。

## 4. 餐厅垂直切片（第一版最小可玩）

1. 南桥/码头旁：**2 张桌** + 1 灶台 + 1 出餐口（VMF 摆）
2. 1 种客人形象，同时最多 **2 桌**
3. **2 道菜**（一道快、一道慢）；做菜读条；手上一次 1 盘
4. E：接单 / 开火 / 取菜 / 上菜
5. 耐心耗尽 → 走人 0 元
6. 23:00 打烊结算（单数、营收、跑单数）

## 8. 键位原则（2026-10-27）

**长期：** 世界上的事尽量「走到面前按 E」。
- 床 → 睡觉
- 商店摊/柜台 → 打开商店 UI
- 餐桌 / 灶台 / 出餐口 → 接单、做菜、上菜

**快捷键先分开、不兼任：**
| 键 | 用途 |
|---|---|
| E | 情境互动（唯一世界交互键） |
| Esc | 暂停：不能操作，画面中央显示「继续」按钮 |
| WASD | 移动 |
| E（床）/ Esc | 农舍床 E 睡觉；Esc 暂停 |
| （旧种地 F/R/G/H） | 种地暂停期可先禁用；恢复种地时再定 |



## 9. 手感时间（第一版）

用现实秒，不跟游戏钟抢：

| 项 | 数值 |
|---|---|
| 快菜读条 | **3 秒** |
| 慢菜读条 | **6 秒** |
| 客人耐心 | **20～25 秒**（入座/点菜起算） |
| 超时 | 直接离席，**0 元** |


## 10. 客人与刷客（第一版）

- **外观**：体素小人换 2～3 种衣服颜色即可，暂不做多种建模。
- **开刷条件**：玩家开始营业之后；**仅空桌**来客。
- **满桌**：不排队、不刷新客。
- **间隔**：上一桌结束后约 **3～5 秒** 再来。
- **23:00**：停刷新客；**桌上未完成订单仍可做完**。


## 11. 开业 / 打烊触发

- **17:00 前**：开业牌不可用（或提示未到营业时间）。
- **17:00 后**：对门口「开业牌」按 **E** → 开始营业、开始刷客。
- **营业中再按 E**：提前打烊（停刷；桌上单可做完）。
- **23:00**：若仍在营业 → **自动打烊**（同停刷）。

## 12. 点单显示（已敲定 2026-10-27）

- 布局：桌上方气泡为主 + 屏幕边简单订单条（两处一起用）
- 气泡：客人桌上头顶；显示菜图标（或简色块代替）+ 耐心进度条；状态变化时可换色（等待绿/黄、着急红、菜好了高亮）
- 侧边订单条：桌号 + 菜名 + 耐心；最多 2 条（第一版只有 2 桌）
- 第一版不做复杂菜单翻页、不做队列列表动画

## 13. 灶台选菜与做菜（已敲定 2026-10-27）

- 客人入座后自动点单（气泡+侧边条立刻出现），无需先去桌边接单
- 到灶台按 E：从当前「未做」订单里选手动选一道开做（只显示有人点的菜）
- 灶台一次只做一道；快菜约3秒、慢菜约6秒，做的时候显示进度
- 做好后进入出餐口，等待玩家来取（已被文末「取菜与上菜」用户自定规则取代：第一版省略单独出餐口取菜，灶台做好后按 E 直接端到手上）
- 玩家手上已有菜时，灶台按 E 不能开新灶（先去上菜）
- 当前没有未做订单时按 E → 提示无单，不空烧

## 客人耐心与超时离席（已敲定 2026-10-27）
- 入座自动点单后开始耐心倒计时，约 20～25 现实秒；气泡与侧边订单条同步减少
- 颜色：满=绿 → 过半=黄 → 快没=红并轻微闪
- 耐心归零：直接起身离席，该单不给钱；气泡/侧边行立刻清掉；桌子变空，隔约 3～5 秒才可能刷新人
- 上菜成功：耐心停算；客人再坐几秒，然后给钱并走人（不是上菜瞬间立刻结账走）
- 做菜途中超时：灶台上该道半成品作废，出餐口不放这盘

## 出餐口取菜和上菜（已敲定 2026-10-27）
- 第一版省略单独「出餐口取菜」步骤：灶台做完菜后按 E，直接把菜端在手上（不做单独取菜交互）
- 端错桌按 E：那桌客人不付钱离席；桌上这盘菜直接消失
- 端着菜时原客超时离开：玩家可把菜丢到垃圾桶，或端给另一桌
- 端给另一桌时，菜名对不对都能放下；若菜不对（或本就不该给这桌），该桌客人不付钱离席（同端错桌）

## 正确上菜与给钱（已敲定 2026-10-27）
- 对的菜 + 对的桌按 E：菜放到桌上，玩家变为空手；该单耐心停算；气泡改为「用餐中」（或小图标）约 3～4 秒
- 用餐结束后：弹出 +金钱（头顶或屏角），Money 加上该菜固定价；客人起身离开；桌子清空；侧边订单行消失
- 第一版无小费，只有固定菜价（具体价钱另节）
- 用餐中不能再对该桌互动；另一桌照常

## 取菜与上菜（已敲定 2026-10-27，用户自定）
- 第一版玩家一人兼做菜与上菜，省略单独「出餐口取菜」步骤
- 灶台菜做好后，在灶台按 E 直接端到手上（一次仍只端 1 盘）
- 端错桌按 E：该桌客人直接不付钱离席；放在桌上的这盘菜立刻消失
- 端着菜时若原点单客人已超时离开：玩家可选择扔进垃圾桶，或把这盘菜端给另一桌客人
- 端给另一桌时菜品不必匹配；放下后该桌客人不付钱离席、桌上菜消失（同端错桌）
- 说明：上文 §13「做好后进入出餐口，等待玩家来取」及耐心节「出餐口不放这盘」等出餐口取菜推荐写法，已被本节用户自定规则取代
## 两道菜名与价钱（已敲定 2026-10-27）
- 快菜：番茄沙拉，售价 15，烹饪约 3 秒
- 慢菜：炖菜，售价 28，烹饪约 6 秒
- 第一版无小费；正确上菜用餐结束后按上表入账
## 垃圾桶交互（已敲定 2026-10-27）
- 厨房旁放垃圾桶（VMF 桶/箱即可），靠近按 E
- 手上有菜时按 E：丢掉变空手；第一版不扣钱
- 空手按 E：短提示「没什么可扔」
- 随时可扔（不要求原客已超时），方便卡死自救
- 不影响灶台正在进行的烹饪进度
